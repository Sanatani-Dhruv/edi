# Edi

- Edi is cli based text editor made in C, inspired by early unix editor: ed

## Next Goal for the Editor:

- It Will Contain sometype of edit replacement system which will be used to edit existing lines
- Like if SomeOne need to add a text at certain Position, and Alt based Command Can be issued to place a certain character somewhere, append at certain lines
and many more things like that, One Example could be Text: 'This need a `-` in the beginning' can be converted edited in place like command on that same line
as 'Alt+I- '.

That Would Insert '- ' in the original sentence, without overwriting whole sentence, Cool Right?
